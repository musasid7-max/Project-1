Website Redesign Project

A case study about improving website design, navigation, and the overall user experience.

Project Overview

This project focuses on redesigning a website to make it more modern, organized, and easy to use. The goal was to improve the user experience while keeping the design simple.

The Challenge

The challenge was to design a website that presents creative projects clearly while keeping the navigation simple and easy to use.

Website Design Preview

The Solution

I created a cleaner layout with better spacing, readable typography, and simple navigation. CSS Grid and Flexbox were used to organize the content and make the website responsive.

Results and Outcomes

The final design concept includes a responsive homepage, a project detail page, consistent navigation, and layouts that adapt to desktop and mobile screens.
